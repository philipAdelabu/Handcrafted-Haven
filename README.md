# Handcrafted Haven Ecommerce

A nextjs backend powered e-commerce

## If you get "Unauthorized" error:

Make sure you're logged in. The cart API requires authentication.

## If you get "Product not found":

Check that the product ID is correct and the product exists in the database.

## If you get "Only X items available in stock":

The product stock is limited. Try adding fewer items.
